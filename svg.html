关键差异对比

维度 USB3 Gen T Tunneling USB3 Gen X Tunneling
隧道模型 端到端（Endpoint-to-Endpoint）隧道，Host 与 Device 直接对话 逐跳（Hop-by-Hop）模型，每经过一个 Router 终止并重新发起
Hub 中的行为 Hub 内无 USB3 Gen T Adapter，数据以隧道形式直接穿透 Hub 的 Device Router Hub 内有 USB3 Gen X UP + DN Adapter，数据在 Hub 内终止，经 Enhanced SuperSpeed Hub 交换后再向下游转发
Host 端 Adapter USB3 Gen T DN Adapter（Host Controller 含 Gen T DFP） USB3 Gen X DN Adapter（无 Gen T）
Device 端 Adapter USB3 Gen T UP Adapter（Peripheral 含 Gen T UFP），Device 作为 Endpoint USB3 Gen X UP Adapter，Device 作为 Function
USB3 角色 Host Controller ↔ Peripheral（T = Tunneled Native 接口） Host ↔ Hub ↔ Function（X = 传统 USB3 Hub 交换模型）
延迟 / 开销 较低（Hub 不做 USB3 层处理，纯路由转发） 较高（每跳都有 USB3 层终止、枚举、交换开销）
Hub 复杂度 低（不需要实现 USB3 Hub 功能） 高（必须实现 Enhanced SuperSpeed Hub）
